**Project Name:DocAppoint — Doctor Appointment Manager.

**Client-live-site::https://docappoint-client-lyart.vercel.app

**.Project Purpose:
The primary purpose of **DocAppoint** is to bridge the gap between patients and healthcare professionals by providing a seamless, secure, and highly efficient digital ecosystem for managing medical appointments. In today's fast-paced world, traditional medical booking systems often suffer from scheduling conflicts, lack of transparency, and cumbersome workflows. DocAppoint solves these real-world challenges through automation and real-time management.


Key Features
**.Secure Authentication & Private Dashboard: Implemented robust user        authentication utilizing Better Auth with session management, ensuring protected private routes (Dashboard, My Bookings, My Profile) that persist smoothly even upon browser refresh without premature logouts.

**.Dynamic Doctor Profiles & Metadata SEO: Features a comprehensive list of medical specialists with a completely dynamic "Doctor Details" page that injects custom, data-driven metadata (Doctor Name & Specialty) directly from the server to maximize SEO rankings and user sharing experience.

**.Instant Appointment Management (CRUD): Patients can seamlessly book appointments via responsive forms, and manage them instantly from their personal dashboard—supporting real-time data updates and cancellations with dynamic UI reactivity and no hard page reloads.

**.Advanced Search & Medical Specialist Filtering: Equipped with a real-time search functionality on the "All Appointments" page, allowing users to filter through available healthcare professionals by doctor names instantly to find the right care.

**.Polished UX with Responsive Design & Theme Toggle: Built with a fully mobile-first responsive architecture utilizing HeroUI/Tailwind CSS, incorporating a dark/light theme toggle, custom loading spinners, elegant feedback toasts, and a fully functional 404 error page.
